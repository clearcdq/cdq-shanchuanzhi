# PACS网络改造技术新旧对比详细表

## 一、整体架构对比

| 维度 | 改造前 | 改造后 | 优劣分析 |

| 架构层级 | 二层扁平网络 | 三层冗余架构 | 改造后分层清晰，易管理 |
