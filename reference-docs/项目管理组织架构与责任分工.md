## 二、详细角色与职责

### 2.1 信息化建设领导小组

| 角色 | 姓名/职位 | 职责 | 权限 | 参与阶段 |
|------|-----------|------|------|----------|
| 组长 | 分管副院长 | - 项目立项审批<br>- 预算批准<br>- 重大决策<br>- 跨科室协调 | 最高决策权 | 全程 |
| 成员 | 信息科主任 | - 技术方案审核<br>- 供应商选择<br>- 质量监督 | 参与决策 | 全技术阶段 |
| 成员 | 财务科主任 | - 资金审核<br>- 采购流程监督 | 财务审批权 | 采购、付款 |

### 2.2 项目管理办公室（PMO）

**项目经理：** [信息科负责人担任]

| 职责 | 详细说明 |
|------|----------|
| 整体规划 | 制定项目计划、资源分配、里程碑控制 |
| 进度管理 | 跟踪每日/每周进度，对比甘特图，预警延期 |
| 质量管理 | 审核技术文档，确保符合标准，把控验收标准 |
| 风险管理 | 维护风险登记册，推动风险应对措施执行 |
| 沟通协调 | 主持周例会，向上汇报，组织评审会 |
| 变更管理 | 管理需求变更，评估影响，审批变更请求 |
| 交付物管理 | 收集、归档所有项目文档 |

**授权：**
- 可调动项目组内所有人员
- 对进度延误有权要求整改
- 对质量问题有权暂停付款

**负责人：** 测试经理（由技术组网络工程师C兼任）

| 测试类型 | 执行人 | 测试内容 | 标准 |

| 物理层测试 | 测试工程师C | Fluke测试Cat6A<br>OTDR测试光纤 | TIA Cat6A标准<br>衰减≤0.5dB |

## 四、决策流程

### 4.1 常规决策路径

```
技术组提出方案 → PMO审核 → 领导小组审批（预算变更/重大风险）→ 执行
```

### 4.2 变更控制流程

```
任意成员提出变更 → 填写《变更申请单》 → PMO评估（范围/成本/时间）
  ↓
影响<3天且成本<5% → PMO批准
影响≥3天或成本≥5% → 领导小组审批
  ↓
批准后 → 更新文档 → 通知全员 → 执行
```

### 4.3 问题升级路径

```
问题发生 → 执行人 → 技术组负责人 → 项目经理 → 领导小组 → 院长
（1小时内未解决）  （4小时内未解决）
```

## 六、人员变更与替补机制

### 6.1 人员 unavailable 处理
- **项目经理 unavailable**：由信息科常务副主任暂代
- **核心网络工程师 unavailable**：由备选的系统集成商技术支持替补（合同中明确）
- **放射科接口人变更**：由科主任指定新的关键用户，并书面通知PMO

### 6.2 人员能力不足
- 施工经理能力不足：施工方需48小时内更换，否则扣违约金
- 测试人员不称职：PMO可要求增派有HCIP认证工程师
